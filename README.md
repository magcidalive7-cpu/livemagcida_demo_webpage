# Economic Data Analysis – South Africa

## Overview
This project analyzes key macroeconomic indicators in South Africa, focusing on inflation and unemployment trends from 2000 to 2022.

## Objectives
- Understand inflation patterns over time
- Analyze unemployment trends
- Explore the relationship between inflation and unemployment

## Tools Used
- Python (Pandas, Matplotlib)
- Jupyter Notebook / Script
- World Bank Data

## Key Insights
- Inflation shows cyclical trends influenced by economic shocks
- Unemployment remains structurally high
- Weak correlation between inflation and unemployment suggests structural economic challenges
