Business Dashboard

Excel / Power BI Dashboard

Project Overview

This project presents an interactive business dashboard designed to monitor sales performance, profitability, and regional trends.

Dashboard Features

  • Sales and profit KPIs
  • Sales trend over time
  • Category performance analysis
  • Regional sales breakdown

Tools Used

  • Microsoft Excel / Power BI

Dashboard Preview

Key Insights

  • Sales trends reveal growth patterns and seasonal fluctuations.
  • Certain categories dominate revenue contribution.
  • Regional differences highlight market opportunities.
  • Dashboard enables quick, data-driven decision making.
